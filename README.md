# VisionPro-3DGSViewer
This project was created using references and packages from **MetalSplatter** that can run in Vision Pro. 
Special thanks to **Scier** for sharing the repository  
**[MetalSplatter – Render 3D Gaussian Splats using Metal on Apple platforms](https://github.com/scier/MetalSplatter)**.

MetalSplatter has been an invaluable resource in understanding the workflow, rendering pipeline, and optimization techniques for real-time Gaussian Splatting on Apple hardware.  
Its clean implementation and well-structured codebase provided a solid foundation that greatly accelerated the development of this project.
